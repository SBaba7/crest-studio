# Security Policy

## Supported versions

The `main` branch is the actively maintained version of Crest Studio.

## Reporting a vulnerability

Please report suspected security vulnerabilities privately to the project maintainers rather than opening a public issue. Include the affected URL or file, reproduction steps, impact, and any relevant logs or screenshots.

Do not include real passwords, API keys, tokens, customer data, or other secrets in a report.

## Scope

This project is currently a client-side React/Vite website. Authentication, authorization, database access, payments, file uploads, and server-side APIs are not part of the current application surface. Those controls must be added at the backend and platform layers when those capabilities are introduced.
